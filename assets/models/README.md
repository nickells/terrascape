# Selected models

Additional reviewed assets join the same searchable library as FurniMesh and
Poly Haven. Files load when selected or when a scene needs them. Source and
license metadata stay in `catalog.json` and in the object inspector.

## Oil palm tree

- Source: [Innerscene's mature oil palm](https://www.innerscene.com/tools/library/3d-parts/mature-oil-palm-tree-with-fruit-bunches-c8b8a16c).
- License: [CC0 / public domain](https://creativecommons.org/publicdomain/zero/1.0/), including redistribution.
- Downloaded November 12, 2026. Original model contains a CC0 dedication in its node metadata.
- Geometry unchanged: 38,766 triangles. Embedded textures capped at 1024 pixels.
- The 256px preview is rendered from the imported GLB.
- Display height: 70 scene units; adjust uniformly with the center scale handle.

To preview this catalog, open `/scripts/preview_furnimesh.html?catalog=models`.
Export thumbnails, then apply the downloaded JSON with
`python3 scripts/apply_model_thumbnails.py EXPORT.json --catalog assets/models/catalog.json`.
